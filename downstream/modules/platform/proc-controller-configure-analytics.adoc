= Configure {Analytics}

[role="_abstract"]
{PlatformNameShort} automatically authenticates analytics transmission using your platform subscription certificate. You can optionally configure a service account if you prefer explicit credential management instead of certificate-based authentication.


.Prerequisites

* A service account created with the *{Analytics} Viewer* role in console.redhat.com. For more information, see Create a service account in {OCPShort} or Kubernetes.

.Context

Use this procedure if you want to configure a service account for analytics instead of using automatic certificate-based authentication.

.Procedure

. From the navigation panel, select *Settings* > *Automation Execution* > *System*.

. Click *Edit*.

. Choose the authentication method for analytics transmission:

   * If you are using automatic certificate-based authentication (the default), skip steps 3 and 4 and proceed directly to step 5 to enable data collection.
   * If you prefer to configure explicit service account credentials instead of certificate-based authentication, continue with steps 3 and 4.



. (Optional) In the field labeled *Red Hat Client ID for Analytics*, enter the client ID you received when you created your service account to retrieve subscription and content information.

. (Optional) In the field labeled *Red Hat Client Secret for Analytics*, enter the client secret you received when you created your service account to send data to {Analytics}.

. In the *Options* list select the checkbox to *Gather data for {Analytics}*.

. Click *Save*.

.Result

Analytics data collection is enabled. If you configured a service account, verify the configuration by running a test job.

.Post-requisites

If you configured a service account, verify that analytics data is being transmitted:

. From the navigation panel, select *Automation Execution* > *Jobs* to launch a job.
. Check link:https://console.redhat.com/ansible/automation-analytics/reports[analytics at console.redhat.com] to confirm that the data is being posted.

To avoid querying incomplete data, align your BI tool refresh schedule with the analytics collection window. For timing details and the refresh offset formula, see xref:ref-controller-data-collection-details[Details about data collected for {Analytics}].

For collection window timing details and processing time figures, see xref:ref-controller-analytics-gathering[Analytics gathering].
