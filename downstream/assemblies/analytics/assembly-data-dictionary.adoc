= {Analytics} Data Dictionary

[role="_abstract"]
{Analytics} sends data fields and schema to the Red Hat Hybrid Cloud Console. This topic describes the available data dictionary and how to verify data currency.


== Overview

The data dictionary outlines the information collected by {Analytics} from the {PlatformName} {ControllerName}, also known as Automation Execution. The linked KB article documents field-level schema definitions for all collected data tables. It does not include a dedicated `last_collected_at` field; collection timing is available through the analytics API discovery response and collection records.

== Data currency verification

No collection-status or backfill-status endpoint exists in the public {Analytics} API. To confirm that a collection cycle has completed and that data is current, query the partition timestamp fields documented in the related links at the end of this topic. For a step-by-step verification procedure, see the related links at the end of this topic.
